# Mean-Variance-Standard Deviation Calculator

Progetto Python del percorso freeCodeCamp "Data Analysis with Python".

## Cosa fa
La funzione `calculate()` riceve una lista di 9 numeri, la trasforma in una matrice 3x3 con NumPy e calcola media, varianza, deviazione standard, massimo, minimo e somma per colonne, righe e sull'intera matrice. Se la lista non ha 9 numeri, restituisce un errore (`ValueError`).

## Strumenti
Python, NumPy

## Come usarlo
1. Installa le librerie: `pip install -r requirements.txt`
2. Avvia: `python main.py`
